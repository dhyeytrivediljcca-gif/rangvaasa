# 🪘 RANGVAASA 2026 — Where Tradition Meets Expression

A modern, high-performance, mobile-first cultural celebration and festival web experience built for **RANGVAASA 2026** — a flagship Navratri/Garba celebration organized by **LJ College of Computer Applications (LJCCA)** in collaboration with **AiRA LAB**, featuring the grand launch of **The Art Adda** creative club.

---

## ✨ Features & Highlights

- **Culturally Immersive Loading Experience**:
  - Features the traditional Gujarati opening call **“એ હાલો…”** (*“Come on, let’s go!”*).
  - Custom vector Gujarati Dholak rocking to an authentic 3-beat Garba cadence with sonic sparks.
  - Gujarati typography powered by Google Fonts Noto Serif Gujarati & Rasa.
- **Hero & Kinetic Visuals**:
  - Transparent cartoon-style Gujarati boy & girl playing Garba with Dandiya sticks.
  - Multi-layered rotating folk mandala background with 5 independent orbital rings, satellites, and decorative nodes.
- **Personalized Digital Pass Generator & PDF Export**:
  - Real-time keepsake pass generation with name and semester.
  - Native client-side high-resolution **PDF download** via `jsPDF` with sanitized filenames (e.g. `Rangvaasa-2026-Dhyey-Trivedi.pdf`) and mobile iOS preview guidance.
  - Alternative PNG export.
- **Dual Festive Theme System**:
  - **Warm Ivory** (Editorial Khadi Tone)
  - **Festive Red** (Royal Gujarati Celebration)
- **The Art Adda Showcase**:
  - Dedicated creative disciplines showcase (Resin Art, Crochet, Chocolate Making, Handmade Crafts).
- **Mobile-First & Accessible**:
  - Fully responsive across all viewports from 320px, 360px, 375px, 390px, 430px up to 4K desktop screens.
  - Touch target ergonomics, no horizontal overflow, and respects `prefers-reduced-motion`.

## 🛠️ Tech Stack

- **Framework**: [React 19](https://react.dev/) + [TypeScript](https://www.typescriptlang.org/)
- **Bundler & Tooling**: [Vite](https://vitejs.dev/)
- **Styling**: Modern Vanilla CSS Design System with fluid `clamp()` tokens & CSS Grid/Flexbox
- **Motion & Interaction**: [Framer Motion](https://www.framer.com/motion/) & [Lucide Icons](https://lucide.dev/)
- **PDF Generation**: [jsPDF](https://github.com/parallax/jsPDF) & [html-to-image](https://github.com/bubkoo/html-to-image)

## 🚀 Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (v18 or higher recommended)
- npm or pnpm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/dhyeytrivediljcca-gif/rangvaasa.git

# Navigate into the project folder
cd rangvaasa

# Install dependencies
npm install

# Start the local development server
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

### Production Build

```bash
# Type check and build for production
npm run build

# Preview the production build locally
npm run preview
```
